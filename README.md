## 📖 About

**MBank v1.1.0** is a simple C++ Console Application developed using **C++** and **Visual Studio**.

This version continues the MBank project with a **Transactions Menu** alongside the main client-management menu.

## 🎯 Purpose

The project was created to practice C++ programming through a small banking-themed console application.

It focuses on:

- Client management
- Basic transactions
- Console menu navigation
